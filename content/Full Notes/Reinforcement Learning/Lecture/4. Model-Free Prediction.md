**Policy/Value Iteration: When the entire environment is given to you. Model free prediction is the process of estimating the value function of an unknown MDP.**

# **Monte-Carlo Learning**:
MC methods learn directly from **episodes** of experience
Simplest possible idea -> value = mean of returns
**Caveat**: All episodes must terminate - this is so that you have the entire return. This is the main difference between MC and TD; in TD, we just estimate the return as we go instead of needing the full return.

**First-Visit MC Policy Evaluation:**
- Evaluating state S
- Increment counter $N(s) \leftarrow N(s) + 1$ and Increment total return $S(s) \leftarrow S(s) + G_t$ the **first** time that state is visited in an episode
- Naturally, Value is estimated as $V(s) = \frac{S(s)}{N(s)}$ 
- By the law of large numbers, $V(s)$ must converge to $v_\pi(s)$ as $N(s) \rightarrow \infty$ 

**Every-Visit MC Policy Evaluation**
- Increment counter and total return **every time** the state is visited in the episode
- First- and Every- visit MCs are identical in **acyclic** MDPs.
- Main difference arises in loopy MDPs, where there is a slight bias.

**Incremental Monte-Carlo:**
The mean of a sequence can be updated incrementally.
$\mu_k = \mu_{k-1} + \frac{1}{k}(x_k - \mu_{k-1})$ 

Translated to MDPS, this can be expressed as:
$V(S_t) \leftarrow V(S_t) + \frac{1}{N(s)}(G_t - V(S_t))$  

In non-stationary problems (for example, updating the policy during control), it can be useful to track a running mean -> forget older episodes.
$V(S_t) \leftarrow V(S_t) + \alpha(G_t - V(S_t))$
If you want to forget more, increase $\alpha$. Decrease if want to forget less.
# **Temporal-Difference Learning**:
Similar to Monte-Carlo learning, with one key difference: **Bootstrapping**

**Monte-Carlo**: $V(S_t) \leftarrow V(S_t) + \alpha(G_t - V(S_t))$

**Temporal-Difference**: $V(S_t) \leftarrow V(S_t) + \alpha(R_{t+1} + \gamma V(S_{t+1}) - V(S_t))$  

The actual return $G_t$ is replaced with the estimated return $R_{t+1} + \gamma V(S_{t+1})$.

| Monte-Carlo                                                  | Temporal-Difference                                  |
| ------------------------------------------------------------ | ---------------------------------------------------- |
| Return only known at the end of episode                      | Can learn online after every step                    |
| Can only learn from complete sequences                       | Can learn from incomplete sequences                  |
| Only works for episodic (terminating) environments           | Works in continuing (non-terminating) environments   |
|                                                              |                                                      |
| High variance, low bias                                      | Low variance, some bias                              |
| Good convergence properties even with function approximation | Doesn't always converge with function approximation  |
| Not very sensitive to initial value                          | More sensitive to initial value due to bootstrapping |
|                                                              |                                                      |
# **TD($\lambda$)**:
Now we try to combine the advantages of both TD and MC methods.
**TD:** Looks one step ahead, calculates mean return, proceeds (one-step return)
- $G_t^{(1)} = R_{t+1} + \gamma V(S_{t+1})$
**MC:** Looks $\infty$ steps ahead i.e. until the end of the episode, calculates mean return, starts new episode.
- $G_t^{(\infty)} = R_{t+1} + \gamma R_{t+2} + \dots + \gamma^{T-1} R_{T}$

Let's define the n-step return
- $G_t^{(n)} = R_{t+1} + \gamma R_{t+2} + \dots + \gamma^{n-1} R_{t+n} + \gamma^n V(S_{t+n})$
Therefore, n-step TD learning:
- $V(S_t) \leftarrow V(S_t) + \alpha(G^{(n)}_t - V(S_t))$
## Forward View TD($\lambda$):
**$\lambda$-return:** Combines all n-step returns $G_t^\lambda = (1-\lambda)\sum^{\infty}_{n=1} \lambda^{n-1}G_t^{(n)}$  
$V(S_t) \leftarrow V(S_t) + \alpha(G^{\lambda}_t - V(S_t))$  
- Update value function towards the $\lambda$-return 
- Looks into the future to compute $G^{\lambda}_t$
- Like MC, can only be computed from complete episodes
## Backward View TD($\lambda$):
**Eligibility Traces**: Combines frequency and recency heuristics; best of both worlds.
![[Pasted image 20250731155217.png]]
$E_t(s) = \gamma \lambda E_{t-1}(s) + 1(S_t = s)$
**Note:** Here, $1(S_t = s)$ is an indicator function, which is = 1 when $S_t = s$ and 0 otherwise.
- Keep an eligibility trace for every state s
- Update value V(s) for every state s in proportion to TD-error $\delta_t$ and eligibility trace $E_t(s)$ 
$\delta = R_{t+1} + \gamma V(S_{t+1}) - V(S_t)$ 
\[$V(S_t)$ is the predicted value, subtracted from TD target $R_{t+1} + \gamma V(S_{t+1})$]
$V(s) \leftarrow V(s) + \alpha \delta_t E_t (s)$ 
- When $\lambda = 0$, $E_t(s) = 1(S_t = s) = 1$. This is directly equivalent to TD$(0)$.
- When $\lambda = 1$, there is no discounting and thus the TD$(1)$ is $\approx$ every-visit MC.

**Offline updates:** Accumulated within the episode, but applied only at the end.
**Online updates:** Applied online at each step.
\[*Reason we don't always use online: sometimes we can only learn from previously collected data(hospital/disaster situations).*]
Also, $\alpha$ is the learning rate.
