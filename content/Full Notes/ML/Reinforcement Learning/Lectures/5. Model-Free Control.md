**On-Policy**: Learn about policy $\pi$ from experienced sampled from $\pi$
i.e. You learn about the consequences of each individual action by sampling from policy $\pi$ itself
**Off-Policy**: Learn about policy $\pi$ from experienced sampled from a different policy $\mu$.
i.e. You learn about the consequences of each individual action by sampling actions from a separate policy $\mu$ 
*sanity check:* the same actions are gonna result in the same outcomes, so you can do this.

As greedy improvement over $V(s)$ requires a model of the MDP, we can improve the policy over $Q(s,a)$. i.e.
## $\pi'(s) = argmax_{a \in \mathcal{A}}Q(s,a)$   

Once again, now we want to combine policy improvement with TD learning. 

# **SARSA: State $\rightarrow$ Action $\rightarrow$ Reward $\rightarrow$ State $\rightarrow$ Action**
- Apply TD to $Q(S, A)$
- Use $\epsilon$-greedy policy improvement
- Update every timestep

# SARSA($\lambda$)
Once again, we try to get the best of both worlds.
**TD:** Looks one step ahead, calculates mean return, proceeds (one-step return)
- $n_t^{(1)} = R_{t+1} + \gamma Q(S_{t+1})$
**MC:** Looks $\infty$ steps ahead i.e. until the end of the episode, calculates mean return, starts new episode.
- $q_t^{(\infty)} = R_{t+1} + \gamma R_{t+2} + \dots + \gamma^{T-1} R_{T}$

Let's define the n-step return
- $q_t^{(n)} = R_{t+1} + \gamma R_{t+2} + \dots + \gamma^{n-1} R_{t+n} + \gamma^n Q(S_{t+n})$ 
Therefore, n-step Sarsa updates:
- $Q(S_t, A_t) \leftarrow Q(S_t, A_t) + \alpha(q_t^{(n)} - Q(S_t, A_t))$

## Forward View SARSA($\lambda$):
Hence define forward-view Sarsa$(\lambda)$:
- $q_t^{\lambda}$ as summation of all n-step Q-returns $q_t^{(n)}$
- Updation of Q: $Q(S_t, A_t) + \alpha(q_t^{\lambda} - Q(S_t, A_t))$
## Backward View SARSA($\lambda$):
Similar to TD($\lambda$), eligibility traces are used here too.
Every state-action pair has one eligibility trace.
$E_t(s, a) = \gamma \lambda E_{t-1}(s, a) + 1(S_t = s, A_t = a)$ 
$Q(s, a)$ is updated for every state s and action a in proportion to TD-error $\delta_t$ and eligibility trace $E_t(s, a)$:
$\delta = R_{t+1} + \gamma Q(S_{t+1}, A_{t+1}) - Q(S_t, A_t)$ 
$Q(s, a) \leftarrow Q(s, a) + \alpha \delta_t E_t (s, a)$

# Off-Policy Learning:
Simple difference: We evaluate target policy $\pi(a | s)$ by observing a *different* policy $\mu(a|s)$
- Can reuse experience generated from old policies
- Can learn about *optimal* policy while following an *exploratory* policy 
- Can learn about multiple policies while following just one
## Q-Learning:
Consider policies $\pi$ and $\mu$:
When learning $Q(s, a)$, 
- Next action is chosen using behaviour policy; $A_{t+1} \sim \mu(\cdot|S_t)$ 
- We also consider alternative action $A' \sim \pi(\cdot | S_t)$ 
- Update $Q(S_t, A_t)$ towards alternate action

**Sarsa:** $Q(S_t, A_t) \leftarrow Q(S_t, A_t) + \alpha(q_t^{(n)} - Q(S_t, A_t))$
**Q-Learning:** $Q(S_t, A_t) \leftarrow Q(S_t, A_t) + \alpha(R_{t+1} + \gamma Q(S_{t+1}, A') - Q(S_t, A_t))$
## Control with Q-Learning:
Target policy $\pi$ is *greedy* w.r.t $Q(s, a)$**:** $\pi(S_{t+1}) = argmax_{a'} Q(S_{t+1}, a')$
Behaviour policy $\mu$ is *$\epsilon$-greedy* w.r.t $Q(s, a)$.
