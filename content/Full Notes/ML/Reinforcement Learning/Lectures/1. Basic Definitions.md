**Reward hypothesis**: There is no goal that cannot be described by some reward/scalar feedback signal $R_t$  and the maximization of this signal

**History**: sequence of actions, observations and rewards - all observable variables upto a time t
#### $H_t = A_1,O_1,R_1, \ldots, A_t,O_t,R_t$

**State**: As the history is way too bulky to feed into the agent every time, you take a function of this history and feed it into the model
### $S_t = f(H_t)$

**Environment State**: $S^e_t$ is the private representation of the environment/complete description of the world at a time t. This is not useful to the model itself, as most of it is irrelevant to the model

**Agent State**: $S^a_t$ is the internal representation of the agent - $f(H_t)$ - used by the agent to perform actions

**Markov State**: Contains all useful information from the history, i.e. "The future is independent of the past given the present" - If you have the state at a time t, the history before that time t is irrelevant as all useful information is stored in just the current information state. No information is lost.
### $\mathbb{P}[S_{t+1} \mid S_t] = \mathbb{P}[S_{t+1} \mid S_1, \ldots, S_t]$

**Fully observable environments**: $S^a_t = S^e_t$ - Formally a Markov Decision Process(MDP)

**Partially Observable Environments:** Agent must construct its own state representation 
$S_t^a = \left( \mathbb{P}[S_t^e = s^1], \ldots, \mathbb{P}[S_t^e = s^n] \right)$

#### Main Terminology: 
**Policy**: The behavior function of an agent
**Value function**: The expected reward the agent can get by following a certain specific policy in a specific state
**Model:** The agent's representation of the environment - predicts what the environment will do next

**Exploration**: Finds out more information about the environment at the cost of losing some existing reward
**Exploitation**: Maximizes reward based on known information
