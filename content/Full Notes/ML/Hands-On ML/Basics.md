### Unsupervised Learning: 
Unlabeled data, system is left to for pattern in the data by itself
Eg. Clustering, Visualization, Dimensionality reduction, Anomaly Detection

**Visualization**: Converts complex and unreadable data into a 2D/3D plottable representation

**Dimensionality Reduction**: Simplifies data without losing too much information, eg. Combines columns of data that are strongly correlated

**Anomaly Detection**: System is trained on normal instances, and so recognizes anomalies/outliers in the data

### Semi-Supervised Learning: 
Partially labelled data; combination of supervised and unsupervised learning

**Eg**. A clustering model groups data into clusters, the user labels the groups, when new data is added a classification model puts data into said groups

### Reinforcement Learning:
System observes the environment, performs actions, and gets rewarded/penalized for the action, and model accordingly learns which actions are good/bad

eg. AlphaGo, evolution, etc.
